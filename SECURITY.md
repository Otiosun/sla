# Security policy

- Nunca versionar tokens, senhas, chaves, JIDs privados, seeds RNG privadas ou dumps de produção.
- `.env.example` contém apenas placeholders.
- Falhas que possam causar corrupção, duplicação econômica ou bypass de autorização são tratadas como bloqueadoras.
- Relatos de segurança não devem incluir credenciais reais ou dados pessoais desnecessários.
