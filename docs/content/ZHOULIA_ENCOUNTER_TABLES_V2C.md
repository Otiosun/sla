# Zhoulia Encounter Tables V2C

This tranche turns the seven typed Vila/Yun encounter pools into real DRAFT encounter tables.

Balance baseline V1 is deliberately isolated from lore/content text:

- Vila dos Arrozais: levels 2–5
- Campos de Yun: levels 4–8
- every species inside a selected pool has equal weight 100
- rarity remains a **table/environment condition**, not a hidden per-species probability

This is an initial mechanical balancing preset, not a canonical narrative fact. It can be tuned later without rewriting the typed area content.

Environmental conditions are fail-closed: DAY/NIGHT, LAND/WATER, rarity and weather requirements do not match if runtime context is absent. Legacy unlock-only tables remain compatible.

The DRAFT materializer resolves semantic species keys to active release-scoped forms, refuses ambiguous multi-form species without a unique canonical default, replaces table entries idempotently, never changes the ACTIVE release pointer and refuses non-DRAFT releases.
